# Hyrule Jobs (Vue 3 + TypeScript practice)

A starter project for learning **Vue 3 with TypeScript**, made while following [this tutorial](https://www.youtube.com/watch?v=UDAVj_vlAr8). The planned app is a small job board ("Hyrule Jobs"). This repo holds the scaffold: Vue CLI, TypeScript, Babel and ESLint set up and rendering a root component.

## Tech stack

Vue 3 (`defineComponent`), TypeScript, Vue CLI 4, Babel, ESLint (`@vue/eslint-config-typescript`)

## Project setup

```bash
npm install
npm run serve     # dev server with hot reload
npm run build     # production build in dist/
npm run lint      # lint and fix
```

See the [Vue CLI configuration reference](https://cli.vuejs.org/config/) to customise the build.
